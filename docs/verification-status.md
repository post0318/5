### 시가총액 — 원인 조사 완료 (2026-09-24)

주가 시점 차이(우리 = EOD 종가, Yahoo = 장중가, 인포맥스 = 09-22 종가)를 빼려고
**주식수(시가총액 ÷ 주가)로 대조**했다. 비교 기준에 인포맥스 종목분석(FactSet,
`globalmonitor.einfomax.co.kr/sss.html#/usa/4/1`, `/facset/getPriceData` 의 `주식수`)
을 추가. 38종목 중 **32종목은 우리 = 인포맥스 정확히 일치**. 불일치 6종목은
인포맥스와 Yahoo 가 서로 일치(V 만 0.55% 차이) → 우리 쪽 원인.

09-23 목록의 SNDK −6.4%·DELL +5.5% 는 재실행 시 0%·+0.66% — 당시 차이의 대부분은

## 3. 알려진 작은 문제
- ~~한국 LTM EPS 가 적자면 빈칸~~ → **수정(09-24, 오너 지시 "적자여도 eps 는 나온다, 빈칸이면
  모두 빈칸 — 일관성")**: `opendart.ts` 가 TTM EPS 를 0 이하에서 버리던 것 제거(음수 그대로).
  재무분석은 TTM 흐름 지표(매출·영업이익·순이익·EPS) LTM 을 연간값으로 대체하지 않음(하이라이트와
  동일하게 빈칸). PER(TTM)은 전 시장 공통 부호 규칙(EPS ≤ 0 → 빈칸, Yahoo PER 대체 안 함).
  LG디스플레이 LTM EPS −2,704 가 하이라이트·재무분석·개요에서 동일, 한국 6종목 화면 간 실패 0.
- 금액 표시는 전 화면 `lib/format.ts` 버림만 사용(시가총액 개요·하이라이트·재무제표·유니버스·
  발표자료 확인). 유일한 예외였던 권리일정 배당금 `toLocaleString`(반올림)을 버림으로 수정.
