# 종목 1페이지 PPT — 요구사항 (오너 2026-10-14)

9월 PPT 기능은 실패했다(아래 「9월 실패 원인」). 오너가 "방법을 바꿔서라도 다시 한번 도전"을 허락하며 준 요구사항이다.
오너: "이정도라도 제대로 구현된다면 난 매우 만족한다." 기준은 **업무에 바로 쓰는 완성품** — "제대로 PPT 를 만든다고 생각해서 이미지 작업, 텍스트 작업 등등을 완벽하게 해야 한다."

## 1. 기본

- **템플릿 = 기본 바탕.** 배경 이미지 등 바탕 서식만 정한다.
- **예시 양식 = 앞으로의 방향.** 그대로 베끼는 대상이 아니라 구성·배치의 방향이다.
- **1종목 1페이지.** 슬라이드 한 장에 아래 일곱 가지가 모두 들어간다. 여러 종목이면 종목마다 한 장(한 파일로 이어 붙일지는 확인 필요).

## 2. 구성 (한 장)

| # | 칸 | 내용 · 방식 |
|---|---|---|
| 1 | 종목명 | 회사명·종목 코드 |
| 2 | 회사 개요 · 투자 포인트 | MCP 로 연결한 에이전트가 작성(§4) |
| 3 | 로고 | 로고 전문 서비스에서 찾아 반영(§5) |
| 4 | 핵심 사업 표시 | 주요 사업 구성 |
| 5 | 주요 재무제표 | 표 개체(칸마다 편집 가능). 숫자는 검증된 값만 |
| 6 | 산업 점유율 | 드롭다운으로 사업 선택 → 검색해 반영, 편집 가능 차트(§3) |
| 7 | 주가 차트 | 주가·지수 이중 축, 시작점 맞춤, 편집 가능 차트(§6) |

## 3. 산업 점유율

- 종목마다 사업이 다르므로 **드롭다운으로 사업을 고른다.** 예: 삼성전자 → 스마트폰 점유율 · 낸드 점유율 · D램 점유율 등.
- 고른 사업의 점유율을 **검색해서 반영**한다.
- 점유율 숫자에는 **출처와 기준 시점**을 함께 표기한다(예: "트렌드포스, 2026년 2분기"). 출처가 확인되지 않은 숫자는 넣지 않는다 — AI 가 숫자를 만들지 않는다.

## 4. 회사 개요 · 투자 포인트 — MCP 에이전트

- 앱이 직접 쓰지 않고 **MCP 로 연결한 에이전트가 작성**한다.
- 주간 리포트 커넥터와 같은 틀: ① 자료 받기(공시 사업 개요·검증된 재무 숫자·최근 뉴스·리포트·작성 규칙) ② 초안 저장 ③ PPT 해당 칸 반영, 저장 전 미리보기.
- 글에 들어가는 숫자는 ①에서 준 값만 쓴다(작성 규칙에 명시). 칸별 최대 줄 수도 작성 규칙에 넣는다(§7).

## 5. 로고

- **로고 전문 서비스 우선**(예: Brandfetch, logo.dev — 회사 도메인 기준이라 공식 로고) → 위키미디어 공용 → 검색은 최후. 무료 한도·이용 조건·한국·일본 수록 범위는 유니버스 종목으로 시험해 숫자로 확인한 뒤 고른다. 비용 0원 범위.
- "IBM logo" 처럼 검색하면 공식·옛 로고·변형이 잔뜩 나온다 → **처음 한 번은 후보 3~5개를 보여 주고 고르게** 한다(투명 배경 여부·해상도 표시).
- 고른 로고는 **회사별로 저장**하고 다시 받지 않는다. 로고가 바뀌었을 때만 다시 고른다.

## 6. 차트 — 편집 가능, 원데이터 유지

- 산업 점유율·주가 차트는 **이미지가 아니라 파워포인트 네이티브 차트**로 넣는다. 원데이터가 내장 엑셀 시트로 들어가 "데이터 편집"으로 바로 고칠 수 있어야 한다 — 반복 편집용("이미지로 하면 수정이 안 되기에").
- 원데이터 시트에 출처·기준 시점 열을 둔다.
- **주가 차트 축:** 주가(왼쪽 축)와 지수(오른쪽 축)를 **실제 값 그대로** 그리고, 두 축의 최소·최대를 조절해 **시작점이 같은 높이에서 출발**하게 한다(예: 주식 100달러, 지수 2,000포인트). **100 으로 환산하는 작업은 아니다.** 두 선이 기간 내내 차트 안에 들어오게, 축 끝값은 깔끔한 숫자로(반올림 때문에 시작점이 조금 어긋나는 정도는 허용 — "최대한 맞춘다").
- 비교 지수(확인 필요): 한국 코스피(코스닥 종목은 코스닥) · 미국 S&P500 · 일본 닛케이225 또는 TOPIX.

## 7. 완성도 기준 — 점검표

통과하지 못하면 보여 주지 않고 고친다. 결과물과 점검표 통과 결과를 같이 보고한다.

**이미지(로고·배경)**: 투명 배경(흰 상자 없음) · 확대해도 깨지지 않는 해상도 · 원래 비율 유지 · 칸 안 정렬·여백 · 배경 위 가독성.

**글**: 칸별 글꼴·크기·굵기 고정(크기표) · 줄 간격·정렬·들여쓰기 · 넘침·겹침 없음 · 맞춤법·띄어쓰기·단위 표기(억원·%·배) · 회사명·사업명 공식 표기.
- 글자 크기는 9월에 엉망이었다(오너). **크기표를 먼저 정해 확인받고 고정**한다(예: 종목명 24pt · 소제목 12pt · 본문 9pt · 표 8pt · 출처 7pt — 실제 값은 템플릿·예시에서 뽑는다). 글이 넘치면 **글자를 줄이지 않고 글을 줄인다.**

**표·차트**: 숫자 = 입력 데이터(결과 파일을 다시 읽어 기계 대조) · 단위·연도 열·음수 표기 · 축 범위 규칙 · 축 제목·범례 · 출처·기준 시점 · 파워포인트에서 "데이터 편집"이 실제로 열림.

**확인 방법**: 슬라이드를 이미지로 렌더링해 예시와 나란히 비교 · 확대해 세부(로고 테두리·글자 잘림) 확인 · 결과 파일을 다시 읽어 글꼴·크기·숫자를 크기표·입력 데이터와 기계 대조. 이 확인 없이 완료라 하지 않는다.

## 8. 진행 순서

1. 템플릿 분석 → 칸 배치표 + 글자 크기표 → 오너 확인
2. 종목 하나로 한 장 제작 — 템플릿을 복제해 바탕은 그대로 두고 칸만 채운다(새로 그리지 않음)
3. 렌더링 비교 · 점검표 · 숫자·글꼴 기계 대조
4. 파워포인트에서 차트 데이터 편집 확인
5. 통과한 결과만 보고 → 오너가 보고 계속 여부 결정

## 9. 필요한 것 · 확인할 것

- **오너가 줄 것**: 템플릿 원본 파일(.pptx) · 예시 양식(파일 또는 캡처) · 첫 시험 종목(없으면 삼성전자).
- **확인 필요**: ① 만들 곳 — 9월 결정은 "앱(5번)에 PPT 생성 코드를 다시 넣지 않고 독립 모듈(ChatGPT 활용)로" 였다. 별도 모듈로 할지, 이번엔 앱 안에 둘지. ② 여러 종목을 한 파일로 이어 붙일지. ③ 비교 지수.
- 재무 숫자: 앱 재무 검증(지표 사전·검증기 설계)이 진행 중이라, 그 전에는 공시 원문에서 직접 확인한 값만 넣는다.

## 9월 실패 원인 (되풀이하지 않을 것)

- 사내 템플릿(11.69×8.27")의 표·차트·이미지 개체를 보존하지 않고 10×7.5" 새 슬라이드를 코드(PptxGenJS)로 다시 그렸다 → 템플릿을 줘도 반영되지 않았고 양식도 구현되지 않았다.
- 들어간 숫자(예상 매출·EPS·PER)의 출처·산식 연결이 불명확했다.
- 칸별 글자 크기를 정하지 않아 크기가 들쭉날쭉했다.
- 결과를 렌더링해 확인하지 않고 완료라고 보고했다.
