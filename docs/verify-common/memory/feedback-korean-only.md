사용자에게 보이는 답변은 전부 한국어로 쓴다. 영어 문장으로 된 보고·요약을 절대 쓰지 않는다(코드·파일명·지표 약어만 예외).

**Why:** 2026-09-27 하루에만 네 번 이상 영어로 답해 오너가 크게 짜증 냄("영어쓰지마라", "진짜.. 짜증나게하네 또 영어네"). 긴 작업 뒤 보고할 때 특히 영어로 새는 경향.

**How to apply:** 보고를 보내기 전 첫 문장·표 머리·목록이 한국어인지 확인. 에이전트 보고를 전달할 때도 한국어로 다시 쓴다.
