값을 못 구하면 다른 출처(Yahoo 등)·다른 정의(사업연도를 LTM 으로)·옛 태그 규칙·근사값으로 채우지 않는다. 빈칸 + 화면에 보이는 사유. 오너가 명시 승인하고 화면에 사유가 표기되는 근사(CLAUDE.md 에 결정 기록이 있는 것)만 예외.

**Why:** 오너 — "그림자 채우기는 절대 하지 말라고 했는데 이번에도 또 나타나고 문제가 심각한데"(2026-09-27). 같은 날 SEC 조회 실패 시 옛 규칙 대체(DE 차입금 651.9억→136.4억), 환율 미고시 시 LTM 에 사업연도 값, 구조 판독 실패를 "구조 없음"으로 캐시하는 경로가 연달아 나왔고, 고친 뒤에도 남은 대체 경로(표지 주식수·클래스 EPS 근사·Yahoo 분기 실패 시 사업연도)를 "남은 작은 구멍"이라며 넘겼다.

**How to apply:** 새 코드·수정 보고에 "기존 대체 유지"가 있으면 그 자체를 결함으로 보고 즉시 빈칸+사유로 바꾼다. 에이전트 지시에 "fallback 금지 — 빈칸+사유" 명시. 대체 경로 목록을 유지하고 승인 근사만 남긴다. 관련: [[feedback-verify-before-display]], [[feedback-exact-match-verification]]
