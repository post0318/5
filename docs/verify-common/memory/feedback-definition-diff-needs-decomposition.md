"정의 차이"를 인정하려면 외부 사이트가 어떻게 구성했는지 줄 단위로 보여야 한다: "우리는 이것, 저쪽은 이렇게 구성(어느 SEC 줄을 빼고/옮김), 원데이터(매출·원가·상각 등)는 다 맞다"가 숫자로 성립할 때만 ②. 성립 안 하면 미결.

**Why:** 오너 2026-09-27 — '외부 정의 분해 불가' 562칸·'외부 단독 이탈' 223칸이 구성 분해 없이 통과로 처리돼 있던 것을 발견하고 "머를 감사하고 검증했다는거지?" 강하게 질책. 확인 안 한 추정(MDLZ 헤지 평가손익)을 원인처럼 말한 것도 지적됨. 비싼 사용량을 쓰고도 핵심 감사를 안 한 셈.
**How to apply:** 외부 차이 분류 전에 외부 소스 줄(StockAnalysis income-statement 줄, Yahoo 필드, 인포맥스 항목)을 받아 SEC 본표 줄과 대조. 원인 추정은 식으로 확인한 뒤에만 말한다. 예: MDLZ SA 영업이익 차 = (SEC 판관비 − SA 판관비) + 본표 자산손상·철수비용 − 인수·매각 이익(4개 연도 정확). 관련: [[feedback-exact-match-verification]] [[feedback-no-false-assurance]]
