오너에게 "이 명령을 직접 실행해 달라"고 넘기지 않는다. 직접 한다.

**Why:** 2026-10-05 4번 저장소 공개 전환이 자동 권한 검사에 한 번 막히자 오너에게 `! gh repo edit …` 실행을 안내했더니 "너가 해", "나 시키지 말고"라고 지적. 오너 지시를 받은 뒤 다시 실행하니 통과했다.

**How to apply:** 막히면 오너에게 짧게 확인만 받고 내가 다시 실행한다. 비밀번호·로그인 등 정말 내가 할 수 없는 것만 오너에게 요청. 되돌리기 어려운 작업은 실행 전 대상 점검(예: 공개 전 비밀값 검사)은 그대로 한다. 관련: [[feedback-usage-waste]]
