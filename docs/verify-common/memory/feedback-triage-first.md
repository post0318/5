매출원가 작업에서 47종목 중 36종목(본표 매출·원가·총이익 또는 원가만 있는 유형)은 이미 SEC 정확 일치로 확인됐고 실제 문제는 10종목(원가 줄 없음)·CAT 뿐이었는데, 이틀 동안 환율 출처·공통모드·판본 판정 등 전 종목 검증 체계 개선에 시간을 써 매출원가를 닫지 못했다(2026-09-27).

**Why:** 오너 — "구현양식이 매출, 원가, 총이익이면 바로 오류 여부가 나오고, 원가만 없다면 빼면 나온다. 문제되는 종목 수가 대폭 주는데 지금 넌 어떤 일을 하고 있니?", "회사에서 차장급이 일을 이따구로 하면 회사 안 돌아가", "대리도 이런식으로 일 안 해", "너무 느리다".

**How to apply:** 지표 착수 시 ① 종목을 본표 구조 유형별로 분류 ② 공시와 바로 대조되는 유형은 한 번에 확인·종결 ③ 남은 문제 종목만 조사·수정 ④ 47종목 전체 검증은 닫을 때 1회, 수정 중엔 해당 종목만. 체계(검증기) 개선도 같은 원칙 — 이미 SEC 정확 일치로 확인된 값은 다시 의심해 검증기를 전면 재설계하지 않는다(2026-09-26~27 공통모드·판본·환율 전면 개편이 그 실수). 문제 항목을 판정하다 막힐 때만 그 부분을 고친다. 오너: "모든 종목 검증체계도 같은 말이야! 이미 검증된 애들이 아닌 문제 애들을 처리하는 방식을 공통으로 하는 건데". 결정 대기로 멈추지 말고 권고안으로 진행 후 모아서 보고. 관련: [[feedback-close-metric-by-metric]], [[feedback-no-false-assurance]]
