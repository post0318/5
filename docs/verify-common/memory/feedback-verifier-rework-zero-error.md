2026-10-11 오너: "이번 작업에는 결코 실수를 용납치 않는다. 검증하는데 맥스를 두달째 쓰는거다."

**Why:** 검증에만 두 달·Max 사용량을 썼는데 시장마다 따로 놀아 같은 결함이 반복됐다. 같은 날에도 내가 오너 지시를 잘못 옮긴 일이 연달아 있었다(외부 대조를 "판정 아님"으로 그림, 한국 시가총액 "확인 후 적용"을 "시장 예외 확정"으로 기록, 일본 EV 결정 때 미국 10-01 결정과의 충돌을 미리 안 보여줌).

**How to apply:**
- 설계(단계별 입력·출력·규칙·실패 처리) 오너 승인 전 코드 착수 금지.
- 단계 완료 = 옛 검증기 결과 대조 + 세 시장 심은 오류 시험 + 독립 감사(Opus, 최종 Fable) — 작성자 자기 승인 금지.
- 오너 결정은 받은 말 그대로 기록, 해석·확대 금지. 결정 전에 관련된 기존 결정(다른 시장 포함)을 먼저 찾아 함께 보여준다.
- 내 판단이 다르면 반대 근거를 먼저 말한다(오너: "내가 말한대로 하지말고 아닌것은 아니라고").
