판번호(ENGINE_VERSION·TTM 판)가 바뀌면 전 종목을 백그라운드로 다시 계산한다(대상 종목만 재계산·대상 먼저 순서 방식은 채택 안 함). 새 저장본이 생길 때까지는 옛 판 저장본을 그대로 응답(사람 대기 0), 교체 시 바뀐 종목·칸(재무제표 칸 포함) 기록 — us-close 가 kr/verification 에 구현 중.

**Why:** 규칙은 종목명이 아니라 공통 조건으로 고치므로 영향 종목을 미리 알 수 없다 — 일부만 재계산하면 모르는 종목에 틀린 옛 값이 조용히 남음. 전체 재계산은 1호기 유휴 시간 약 25분(51종목, 10-09 실측 1,479초), 비용 0. 오너 "업데이트 후 새 값 반영 로직으로 유지".
**How to apply:** 판번호는 저장본에 영향 있는 규칙 변경 때만 올린다(표시 변경으로 올리지 말 것).
