이미 정해진 기준·실측(예: SEC 공시 원본 디스크 캐시 → 47종목 약 10분, 7종목 묶음 약 80초)을 무시하고 캐시 도입 전 방식("SEC 순차 조회라 40분")으로 설명했다가 오너가 강하게 지적(2026-09-27 — "왜 앞에서 정한 기준을 이어서 못하지?").

**Why:** 오너는 여러 세션에 걸쳐 결정·개선을 쌓아 왔고, 그걸 이어받지 못하면 같은 설명·결정을 반복해야 한다.
**How to apply:** 소요 시간·원인·동작 방식을 말하기 전에 docs/handoff-verification.md 와 실제 로그 타임스탬프를 근거로 확인한다. 근거 없는 추정은 말하지 않는다. 관련: [[feedback-no-false-assurance]]
