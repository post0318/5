## 1. 원칙 (오너)

1. **화면 내용은 한국·미국·일본·그 외 모두 같다.** 다른 것은 값의 원천과 산식 일부뿐, 회계 원칙은 같다(2026-10-11). → 화면 항목별 정의 한 벌 + 시장별 원천 + **근거 있는** 산식 차이만.
2. **시장 고유 항목은 추가 행으로 남긴다**(일본 경상이익 등).
3. **재무제표 화면은 원본 표현 그대로**(공시 계정). 이 사전은 하이라이트·재무분석·개요·유니버스·컨센서스 값만 다룬다.
4. **내 판단이 다르면 반대 근거를 먼저 말한다**("내가 말한대로 하지말고 아닌것은 아니라고").
5. **그림자 채우기 금지**: 못 구한 값을 다른 출처·정의·근사로 조용히 채우지 않는다. 빈칸 + 사유. 예외는 오너가 승인하고 화면에 표기한 근사뿐(예: 한국 사업연도 시가총액 KRX 실패 시 연말 종가 × 현재 주식수 + ⚠, 2026-10-04).
6. **EPS = 전체(계속 + 중단영업)**. 주당 지표는 흐름식(주당값끼리 더하기·빼기) 금지 — 순이익 ÷ 주식수.
7. **같은 기준 원칙**(2026-10-02): 분자·분모(또는 EBITDA 의 영업이익·감가상각, EV 의 차입금·EBITDA)는 같은 범위.
8. **부호 규칙**: 배수의 분모가 0 이하면 빈칸(전 시장).
9. **한 값 한 계산**: 같은 이름의 값은 화면이 달라도 같은 함수·같은 원천.
10. **금융업·금융 자회사 EV = 전 시장 미국 규칙**(2026-10-11): 은행형은 이자부 차입금(예금 제외)으로 채움, 금융 자회사는 제조 부문 차입금, 부문을 못 나누면만 빈칸.
11. 앱과 검증기는 같은 계산 코드를 import 하지 않는다(공통모드 방지) — 이 사전이 두 쪽의 공통 명세다.
12. 외부 미해결은 완료 차단(정의 다름·외부 단독 이탈은 미해결 아님) — 판정 정의는 `00-handoff.md`.

## 2. 공통 부품 (확정 정의)

표기: **정의** / **원천** 미·한·일 / **예외(근거)** / **결정 출처** / **지금 앱과 다른 점**(§4 번호).

### P1. LTM(최근 12개월)

- **정의**: 손익·현금흐름 = 최근 사업연도 + 당기 누적 − 같은 보고서의 전기 누적(분기 공시 시장에선 최근 4개 분기 합과 같다). 구성 값이 하나라도 없으면 **빈칸 + 사유**(연간값 대체 금지). 재무상태표·주식수 = 손익 LTM 의 마지막 기간말.
- **원천**: 미 = 10-Q 분기값 4개 합(20-F 는 FY + 당기 누적 − 전년 누적), 결손·마지막 연간값 550일 초과는 빈칸(SR:711 `ltmFlowOf`, SR:752, SR:677 `ltmAnchor`). 한 = DART 사업보고서 + 최근 분기·반기 보고서 누적 − 그 보고서의 전기 누적(정정·재작성 반영, OD:512~535). 일 = 有報 + 半期報告書 누적 − 그 반기보고서의 전기 반기(JS:390~405).
- **예외(근거)**: 일본은 반기 누적(EDINET 2024-04 부터 반기·연간만 — 공시 주기). 한국 3~5월(사업보고서 뒤·1분기 보고서 전)과 일본 반기보고서 전에는 LTM = 최근 사업연도 그대로(OD:457~483, JS:433~437 `ltmIsFy`) — 그 기간 최신 12개월이 사업연도다.
- **결정 출처**: 미국 LTM 분기합 2026-09-28, 한국 LTM 구성 2026-10-10, A3(대체 금지 — 원칙 5).
- **다른 점**: 한국 분기 누적 없으면 연간값 대체(OD:526~529, 688~716) → **K3**.

### P2. 순이익(지배)

- **정의**: 지배기업 소유주 귀속 당기순이익. 순이익·순이익률·OCF/순이익·배당성향·EPS·ROE 모두 이 값. **ROA 만 연결 순이익**(비지배 포함, 표시명 「ROA(연결)」).
- **원천**: 미 = `NetIncomeLoss` → `ProfitLoss − NetIncomeLossAttributableToNoncontrollingInterest` → 보통주 귀속(PS:79). 한 = `ifrs-full_ProfitLossAttributableToOwnersOfParent`(연결 손익계산서 「지배기업의 소유주에게 귀속되는 당기순이익」). 일 = `ProfitLossAttributableToOwnersOfParent`(IFRS·J-GAAP), 연결 없는 회사만 `ProfitLoss`(JE:303~311).
  ROA(연결) 분자: 미 = `ProfitLoss`(없으면 NetIncomeLoss + NCI 순이익), 한 = `ifrs-full_ProfitLoss`, 일 = `ProfitLossIFRS`·`ProfitLoss`(当期利益).
- **예외**: 없음.
- **결정 출처**: A1 결정 2026-10-12 「나로 가면 된다」(관행 실측: FnGuide 순이익률·ROE 지배·ROA 연결).
- **다른 점**: 한국 순이익 = ProfitLoss(KH:19·103, KA:22, OD:334, KO:62) → **K1**. 미·일 ROA = 지배(AN:979, JA:74) → **C5**.

### P3. 자기자본 ① 지배주주 자본 ② 자본총계

- **정의**: ① 지배기업 소유주 지분 — PBR·BPS·ROE·재무레버리지·자기자본비율(일본 금융). ② 자본총계(비지배 포함) — 연결 부채·차입금과 짝.
- **사용처(결정)**: 부채비율·총차입금/자기자본·순차입금/자기자본 분모 = **한국 ② 자본총계, 미국·일본 ① 지배주주 자본**(시장 관행). ROE·재무레버리지 = 세 시장 **평균** ①.
- **원천**: ① 미 = `StockholdersEquity`(기준일 ±7일, PS:228 `parentEquityOf`), 한 = `ifrs-full_EquityAttributableToOwnersOfParent`(KE:486~498), 일 = IFRS `EquityAttributableToOwnersOfParentIFRS` / J-GAAP `NetAssets − NonControllingInterests − SubscriptionRightsToShares`(JE:322~326). ② 한 = `ifrs-full_Equity`(KA:27), 일 = `EquityIFRS`·`NetAssets`(JE:317~319).
- **예외(근거)**: 레버리지 분모가 한국만 자본총계 — 오너가 시장 관행으로 정함(Q1, 초안 추천은 자본총계 통일이었음).
- **결정 출처**: Q1 2026-10-12 「다」, A2 2026-10-12 「가」.
- **다른 점**: 한국 ROE·재무레버리지 분모 = 자본총계(KA:368·371) → **K2**. 일본 레버리지 3행 분모 = 자본총계(JA:168~171) → **J7**.

### P4. 사업연도 EPS

- **정의**: 회사 공시 희석 EPS(전체 = 계속 + 중단). 전체 EPS 미공시면 계속 + 중단 주당이익 합 → 희석 없으면 기본(희석 증권 없음). 분할·병합·무상증자가 있으면 **수정 기준**(P15).
- **원천**: 미 = `EarningsPerShareDiluted`(분할 보정) → Class A → 계속 + 중단 희석 합 → 보통주 귀속 ÷ 희석 가중평균 → 근사(라벨)(PS:153 `fyEps`). 한 = `ifrs-full_DilutedEarningsLossPerShare` → 기본 → 계속(`…FromContinuingOperations`) + 중단(`…FromDiscontinuedOperations`) 합(KE:505~575). 일 = 有報 경영지표 `DilutedEarnings…SummaryOfBusinessResults` → 「－」면 기본 → 본표 EPS(JS:546~560).
- **예외(근거)**: 대체 사슬 순서만 시장별(공시 형식 차이).
- **결정 출처**: EPS 전체 원칙(2026-10-01, KE:511~517 주석), A23.
- **다른 점**: 미국 기본 EPS 경로에 계속 + 중단 합 없음(DELL FY2022) → **U1**. 한국 서진시스템 FY2022·23 = 계속영업 EPS(450·−56, 전체 43·−603) → **K11**. 한국 분할 재작성 EPS × 미보정 종가 → **K10**.

### P5. LTM EPS

- **정의**: LTM 순이익(지배, 보통주 귀속) ÷ 현재 보통주 주식수. 주당값 흐름식 금지. 분할 사건이 LTM 구간에 있으면 수정 기준(P15)으로 맞춘다. LTM 이 사업연도와 같으면(P1 예외) 사업연도 EPS.
- **원천**: 미 = PS:124 `ltmEpsOf`. 한 = LTM 지배 순이익(P1·P2) ÷ 현재 주식수(**주식수 종류는 §5 M2**). 일 = LTM 지배 순이익 ÷ 반기말 유통주식수 × 그 뒤 분할(JE:561~583).
- **결정 출처**: 원칙 6, A4, 분할 수정 기준(2026-10-14).
- **다른 점**: 한국 = 분기 EPS 흐름식, 분기 EPS 없으면 ProfitLoss ÷ (연간 ProfitLoss ÷ 연간 EPS)(OD:543~561) — LS일렉트릭 LTM PER 17.34(손계산 68.54)·가온전선 78.98(129.47) → **K4**.

### P7. 시가총액·열 기준 가격

- **정의**: 열 기준일 보통주 종가 × 그 날 보통주 주식수(P6). 사업연도 열 = 결산일(이전 마지막 거래일) 종가 × 결산일 주식수, LTM 열 = 최근 마감 종가 × 현재 주식수, 예상 열 = 없음. 시가총액은 **그 날 실제 주식 기준**(분할 수정 안 함). PER·배당수익률에 쓰는 가격은 주당값과 같은 주식 기준(P15).
- **원천**: 미 = secBasisBars 종가 × SH 주식수(HL:358~383). 한 = KRX MKTCAP(보통주, 상장주식수 × 종가) — 사업연도 = 그해 마지막 거래일, 실패 시 연말 종가 × 현재 주식수 + ⚠(KH:126~138, KE:445~464). 일 = 결산일 직전 10일 내 Yahoo 종가 × 그 뒤 분할(실제 가격 환원) × 유통주식수, LTM = 현재가 × 반기말 주식수 × 그 뒤 분할(JE:545~559).
- **예외(근거)**: 한국 사업연도 근사 = 오너 승인 근사(2026-10-04 「근사 + ⚠ 표시」).
- **다른 점**: 일본 개요 시가총액 null 이면 Yahoo marketCap(SA:703) → **J3**.

### P8. EV 브릿지

- **정의**: EV = 보통주 시가총액 + 이자부 총차입금(P10) + 우선주 + 비지배지분 − 현금성자산(P9). 기준일 같은 값만. 예상 열 없음.

- **OCF**: 현금흐름표 영업활동 합계(계속영업 태그만 있는 해는 그 값). 미 = 현금흐름표 화면 행 `cf:total:영업활동 현금흐름` → `NetCashProvidedByUsedInOperatingActivities`(…ContinuingOperations)(HL:531, AN:318·341). 한 = `ifrs-full_CashFlowsFromUsedInOperatingActivities`. 일 = `NetCashProvidedByUsedInOperatingActivities(IFRS)`(JE:374).
- **CapEx(결정)**: 세 시장 = **현금흐름표 본표의 유형자산 취득 줄**. 회사가 유형·무형을 **한 줄로 섞어 적었으면 그 줄 그대로**(NVDA·LRCX·GEV·V·MAR·DELL·DAL, 일본 「有形固定資産及び無形資産…」·「有形及び無形固定資産の取得」), 무형·소프트웨어·임대장비·인수 등 **따로 적은 줄은 넣지 않는다**(IBM 소프트웨어·HLT·CAT 임대장비·MCD 가맹점 인수·VST 배출권).
  - 미 = 현금흐름표 화면 행 `cf:투자활동 현금흐름:유형자산 취득` → `PaymentsToAcquirePropertyPlantAndEquipment`·`PaymentsToAcquireProductiveAssets`·`PaymentsForCapitalImprovements`·`CapexComponentsDerived`(HL:93~98). 한 = `ifrs-full_PurchaseOfPropertyPlantAndEquipmentClassifiedAsInvestingActivities` 「유형자산의 취득」(KH:21). 일 = 투자활동 有形固定資産(또는 有形及び無形固定資産) 取得·購入 줄(売却 제외).

### P18. 평균 vs 기말 (Q11)

- **정의**: 수익성·효율 지표(ROE·ROA·ROIC·총자산회전율·재무레버리지·DSO·DIO·DPO) = **평균**((기초 + 기말)/2, LTM 은 최근 기간말 + 1년 전 같은 기간말). 상환능력·유동성(총차입금/EBITDA·CFO/총차입금·FCF/총차입금·유동비율·당좌비율·현금비율·**CFO/유동부채**)과 밸류·레버리지 잔액 비율(PBR·부채비율·차입금/자본·알트만 Z) = **기말**. 기초가 없으면 빈칸 + 사유(기말 대체 금지).
