### 4. 앱(jp/app 8591851) 지금 코드

- `src/lib/markets/jp/jp-ev.ts` `isCash`: 유동자산 안의 `CashAndCashEquivalentsIFRS`·`CashAndDeposits`·`CashAndCashEquivalents` 태그, 또는 이름표 `現金及び現金同等物|現金及び預金|定期預金|短期投資|有価証券|短期運用有価証券|短期運用資産`. 정의 주석: 「その他の金融資産 は除外(韓国 "その他流動金融資産 除外"と同じ)」.
- `DEBT_RE = /借入|社債|有利子負債|リース負債|リース債務|コマーシャル・?ペーパー|借用金|^(償還期)?長期債務$|資金調達に係る債務/` 이다. 預金·貯金은 제외한다. 본표에 리스 줄이 없으면 주석 리스를 더하고, 못 정하면 EV 를 공란으로 둔다.
- 하이라이트 주석: 「EV = 시가총액 + 총차입금(사채·차입금·CP·리스부채) + 비지배지분 − 현금성자산(現金及び現金同等物·現金及び預金 + 定期預金·短期投資·有価証券)」.
- 관찰(범위 밖, 수정하지 않음): 6501 日立 앱 차입금이 短期借入金 하나뿐이고, 7267 ホンダ 는 0 이다. 둘 다 정규식에는 걸리는 이름표(長期債務·資金調達に係る債務)인데 값이 빠졌다. 원인은 조사하지 않았다.
