**정리**: Q2 결정대로 "손익 이자비용, 없으면 빈칸"이면 —
- 한국: **FY2023 이후는 거의 다 채워진다(93%)**, FY2022 는 다음 해 보고서 전기 칸에 기대야 하고, **FY2021 은 사실상 빈칸**(이자비용 주석 태그 0칸).
- 일본: **회사 단위로 갈린다**. 21종목은 앱 5칸 내내 있고(은행 2종목은 資金調達費用), 17종목(CF만·구성요소만·金融費用만·줄 없음·US GAAP)은 앱 5칸 어디에도 손익 이자비용 합계 태그가 없다.
- 두 시장 모두 **"이자비용" 태그 하나를 기계적으로 고르면 범위가 다른 값이 섞이는 칸이 있다**(한국 20칸 — 아래 "후보 간 실질 차이"). 태그 우선순위와 범위(리스 이자·중단영업·社債利息 포함 여부)를 사전에 정해야 한다.

### 판정 규칙(측정용, 앱 규칙 아님)

1. 출처: 그 해 사업보고서 XBRL(당해) → 없으면 다음 해 사업보고서의 전기 칸(†). 같은 해 접수번호가 여럿이면 최신(정정본).
2. 칸 조건: 연결(`ConsolidatedAndSeparateFinancialStatementsAxis=ConsolidatedMember`), 기간 350~380일·종료 연도 = FY, 다른 차원 없음 또는 `dart:ReportedAmountMember` 만.
3. 태그 순서(같은 출처 안): **DIE** `dart:InterestExpenseFinanceExpense`(금융원가 주석의 「이자비용(금융원가)」 DART 전용) → **IE** `ifrs-full:InterestExpense`.
   IE 를 뒤로 둔 이유: IE 는 부문정보 합계·범주별 금융상품 표에도 무차원으로 쓰여 범위가 섞인다(한화에어로스페이스 FY2024: IE 257,220,098천원 = 부문이자비용 합계, 손익계산서·금융비용 주석은 242,539,778천원 — 원문 확인).
4. A 가 없으면: **ADJ** 현금흐름표 「이자비용」 조정(`ifrs-full:AdjustmentsForInterestExpense`·`dart:AdjustmentsForInterestExpenses`) → 회사 고유 태그(한국어 이름표가 정확히 「이자비용」 등) → 차원값만 → 구성요소만(리스·사채) → 연결 없음(별도만) → 금융원가만 → 후보 없음 순으로 사유를 붙인다.
5. 값이 {x, −x} 로 둘이면 x(범주별 금융상품 표가 음수로 태깅 — 효성중공업 원문 확인), 0 과 다른 값이 함께면 0 을 뺀다(⚠ 표시).

## 일본 — 42종목 × 앱 하이라이트 FY 5칸

FY 이름은 앱과 같은 규칙(기말 연도: 3월 결산 FY2026 = 2026-03 기말). 앱 5칸은 3월 결산 FY2022~FY2026, 12월 결산 FY2021~FY2025, 8월 결산(ファーストリテイリング) FY2021~FY2025.
