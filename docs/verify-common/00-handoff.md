## 판정 정의 (가설 — 지난 결과로 측정 후 고정)
칸 = 종목×화면×지표×기간. 입력 앱 값 A, 기대값 E(원자료로만, 독립/공통모드 표시), 외부값 X1..n.
- 가. 원자료: 조회 실패→검증불가 / 기대 빈칸·A 빈칸→일치 / E 있고 A 빈칸→불일치 / 기대 빈칸·A 있음→불일치 / 정확 일치(정수 완전, 소수 1e-14)→독립 일치 또는 공통모드 일치 / 다름→불일치.
- 나. 외부(각 값): 같은 기간·정의·표기 반올림 안 같음→일치 / 식이 성립하는 차이→원인 확인 / ⑤에서 정의 다름→참고 / 다른 독립 외부는 앱과 정확 일치인데 이것만 다름→외부 단독 이탈 / 그 외→미해결 / 소스 없음→외부 없음.
- 다. 최종: 원자료 불일치→실패 / 독립 일치+미해결 아님→통과 / 독립 일치+외부 없음→통과(외부 미확인, 완료 보고 제외) / 독립 일치+미해결→미해결(완료 차단) / 공통모드+독립 외부 2곳 이상 정확 일치·어긋남 없음→외부 확인 통과 / 공통모드+그 외→공통모드 또는 미해결 / 검증불가→검증불가.
- 측정: 미국 47(2호기 /tmp/full-us-1011.log 실행분)·한국 30·일본 42 결과에 적용 → 남는 미해결 수, 알려진 오류(079550 리스 단위, D1~D3, DELL 기본 EPS) 검출, 공통모드 외부 1곳/2곳 기준 비교.
