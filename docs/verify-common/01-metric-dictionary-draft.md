## 1. 확정된 공통 원칙 (오너 결정, 바꾸지 않음)

- 화면 내용은 전 시장 같다. 다른 것은 값의 원천과 근거 있는 산식 차이뿐(회계 원칙은 같다). 시장 고유 항목(일본 경상이익 등)은 추가 행.
- 재무제표 화면은 원본 표현 그대로 — 사전은 하이라이트·재무분석·개요·유니버스·컨센서스 값만 다룬다.
- 그림자 채우기 금지: 못 구한 값을 다른 출처·정의·근사로 조용히 채우지 않는다. 빈칸 + 사유(승인·표기된 근사만 예외).
- EPS = 전체(계속 + 중단영업). 주당 지표는 흐름식(주당값끼리 더하기·빼기) 금지 — 순이익 ÷ 주식수.
- 같은 기준 원칙(10-02): 분자·분모(또는 EBITDA 의 영업이익·감가상각, EV 의 차입금·EBITDA)는 같은 범위.
- 부호 규칙: 배수의 분모가 0 이하면 빈칸(전 시장, `multiples.ts`).
- 금융업·금융 자회사 EV = 전 시장 미국 규칙(10-11): 은행형은 이자부 차입금(예금 제외)으로 채움, 금융 자회사는 제조 부문 차입금, 부문을 못 나누면만 빈칸.
- 배당금 지급 = 재무·영업활동 분류 모두(10-12).
- 한국 시가총액 주식수 = 외부 사이트(FnGuide·네이버) 기준을 숫자로 확인한 뒤 적용(10-11, 미정).
