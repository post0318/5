## 참고 — 같은 페이지의 다른 주식수 정의(이번 결정 범위 밖, 사전 작성 때 참고)

FnGuide 는 지표마다 주식수가 다르다(Snapshot 정의문):
- BPS = 자본총계(지배) / **수정기말발행주식수(자사주차감)**
- EPS = 당기순이익(지배) / **수정평균발행주식수**

시가총액(상장주식수)과 BPS(자사주 차감)가 다르므로 FnGuide PBR(종가 / BPS)은 시가총액 / 지배자본과 같지 않다.
앱 BPS·PBR 정의는 지표 사전에서 따로 정한다(이 문서는 시가총액만).
